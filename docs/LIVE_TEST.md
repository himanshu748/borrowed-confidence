The test exercised the actual Express application's image validation, consent requirement, private session ownership, server-side provider adapter, file registration, signed uploads, task creation, polling and output download. The local test server was closed afterwards. No credential-enabled public server was left running.

Authentication was checked separately through the documented read-only pricing endpoint. The configured credential was proxy-delivered. Its real value was never read, printed, committed or copied into a file. The adapter placed the provided credential handle only in the documented Authorization header on the fixed provider API host. Image uploads did not carry that header.

## Synthetic input provenance

The user authorized generating demo assets and testing them through YouCam. Both inputs were generated specifically for this test using the image-generation tool:

- synthetic-person.jpg: a fictional adult South Asian man in a plain grey T-shirt, front-facing, not based on a real person
- synthetic-blazer.jpg: a product-only reference for one unbranded navy blazer

They are not stock portraits, real customer photos or evidence of a real person's endorsement. The landing page's stock subjects were not sent to YouCam. Input and result files are in live-evidence. All must be labeled synthetic demo assets when used publicly.

## What the output demonstrates

A real YouCam request completed successfully and returned an image of the synthetic subject wearing a navy blazer resembling the reference. The result preserved the broad pose and background sufficiently for a recognizable demo comparison. This is genuine provider output, not an image generated by a different tool and relabeled as YouCam.

## Important observed limitation

The output replaced the grey T-shirt rather than preserving it as an underlayer beneath the blazer. The generated blazer exposes the upper chest. Therefore this test does not demonstrate reliable layering, a complete interview outfit, exact garment fidelity or physical fit. Do not present it as any of those. A future test may need a different supported reference strategy or an explicit whole-outfit reference. Do not spend additional units without authorization.
